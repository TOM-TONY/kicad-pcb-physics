## Specify a study

The generated `settings.json` is a complete example. All geometry coordinates in the input are millimetres in board coordinates. Positive depth points from the top surface toward the bottom. Voltage and current phasors use consistent RMS amplitudes; exported current density is averaged for display. The scalar-field legend gives the range on the selected layer.

| Section | Input and interpretation |
|---|---|
| `material` | Layer names mapped to copper thickness and depth in mm, plating in mm, and copper resistivity at the operating temperature in Ω m. |
| `electrical` | Select a net, grid pitch, optional clipping rectangle and terminals. Each terminal has a list of pin names or disks (`{"xy":[4,6],"layer":"F.Cu","radius_mm":0.2}`) and signed amperes. Use opposite unit currents for a two-point resistance. In a multi-terminal solve the first-to-last voltage and every terminal potential are reported. The AC slab solution accounts for symmetric skin penetration. Set `return_spacing_mm` to include a local parallel-plate external inductance. |
| `thermal` | Named boundary cases. Give the material-averaging pitch and finer solution pitch, foil and dielectric thickness, air temperature, surface film coefficients, package losses, contact resistances, and electrical case names in `dc_cases`. For a fan, enter a justified forced-convection coefficient. For a heat sink, enter the combined component-to-air resistance in `part_to_air_k_w`. Sweep these uncertain inputs. Model densities are fixed on material tiles during solution-grid refinement. |
| `pdn` | For each capacitor, define two ordered same-net pad pairs, from the supply pin to the capacitor and back to the return pin. Define C, ESR, ESL and a piecewise capacitance fraction versus bias. The conductor path, spreading-width approximation, internal closure and mutual terms enter the loop inductance. A series-RL source feeds all coupled branches. A uniformly sampled periodic current at the port gives AC ripple by Fourier synthesis. Clone cases to compare values or additional populated pads. To compare a moved footprint, supply its filled board copy. |
| `electrical.field`, `radiation`, `receivers` | Select probe coordinates and height. A prescribed exciting path and distributed sheet currents produce magnetic and induction fields. Electrostatic fields require prescribed charge nodes, capacitances and an image plane. A closed path supplies a magnetic-dipole far-field estimate only where the electrical-size and distance checks pass. A receiving path needs its return to define magnetic flux, a specified uniform incident field, and source/load impedances for harness pickup. |
| `returns` | Identify the signal, reference net and paired layers. Results locate straight-track projections that lose reference coverage. The electrical study can include the exciting trace (`exciting_legs`) or an explicit path, then report complex plane potentials, via currents, and RMS lateral return spread at each frequency. |

Set `simulator.executable` or `NGSPICE_BIN` for a custom ngspice installation. The passive one-port is checked against the independent simulator at every requested frequency by default. `simulator.backend="ltspice"` and `LTSPICE_BIN` select a separately installed alternative. `simulator.enabled=false` runs only the mathematical circuit solution. Set `kicad_python` or `KICAD_PYTHON` for the geometry bridge. Matrix solves use SciPy's installed backend on each platform.

For uniform incident-field screening of every track and pad, add an `exposure` case with `name`, `frequency_Hz`, `E_V_m`, `B_T`, `reference_xy_mm` and `reference_depth_mm`. Optional per-pin `terminations` specify complex `harness_V`, `source_ohm` and `load_ohm` as real/imaginary pairs. Each result assumes a measurement contour returning directly on that reference plane. Spatially nonuniform fields or a different cable contour need different excitation. For the emitting-sheet model, `field.sheet_charge` accepts `image_z_mm`, `epsilon_r` and `common_mode_V` to estimate local charge from the computed sheet potential and area. The parallel-plane approximation does not resolve edge fringing.


For geometry-conforming thermal FEM, set `thermal.<case>.method="conformal"`, `grid_mm`, `near_parts_mm`, `snap_mm` and `simplify_mm`. The mesh follows etched copper, pad and barrel boundaries. Repeat with a finer partition and fixed geometry tolerances to assess peak convergence. The geometry backend needs GEOS with constrained triangulation support. Inspect integration and energy residuals. A previous DC solve can supply a `loss_cells_file` containing the input board SHA-256 and per-layer `heat_cells` in watts. In dense maps the HTML displays the highest temperature per display cell; full numerical fields remain in the results JSON.

A `transients` entry can replay a local circuit template; the example includes a charging pulse. Each parameter is a fixed number or a link to a PDN case, branch and extracted quantity. Put numerical placeholders in the deck as `@@key@@`. Name the transient measurements to read and the footprints to annotate. Simulator, template and optional includes stay on the machine. For a driven return with a matched external path, `radiation_distance_m` evaluates the magnetic dipole of distributed copper currents and their closed excitation circuit, with a numerical current-closure check.

DC multiport extraction supplies a symmetric resistance matrix for parallel capacitor branches, including common supply and return copper. The simulator netlist realizes shared resistive drops using current-controlled series voltage sources. Local magnetic fields are integrated at the original solved segment positions. An induced EMF also drives closed copper islands with no external terminals. Generated reports, geometry caches and data overlays contain recoverable board geometry; keep private-board outputs within the same disclosure boundary as the input board.


## Transmission lines and differential pairs

Generate the reference example with the KiCad interpreter:

```sh
"${KICAD_PYTHON:-python3}" examples/generate_pair.py output/pair
pcb-physics output/pair/pair.kicad_pcb output/pair/settings.json output/pair/results
```

Set `transmission.routes` to net names or arrays of two net names, or use `detect_pairs: true`. Default suffixes include `_P/_N` and `+/-`. Supply `pair_suffixes` as pairs of literal suffixes for other conventions. For branches, specify `endpoints` by net, with two pad names or two objects containing `xy` and `layer`. The centerline walker takes the shortest connected trace route between endpoints. Filled copper shortcuts and component-internal connections are outside that graph. A `packages` entry at a net's far end supplies `length_mm`, `velocity_m_s` and `z_ohm`. Copper depths determine the active through-barrel length and remaining stubs. A via is a declared uniform section (`via_z_ohm`, default 50 Ω); open stubs use a shunt transmission-line model. Via and package losses are approximate.

Define the return net in `reference` and give each signal layer an entry in `stack`. Supply the opposite `plane`, substrate `er`, `tan_delta` and optionally a `second_plane` on the other side of the trace for stripline. External layers accept `mask_mm`, `mask_er` and `mask_tan_delta`. Cross sections use rectangular copper, a uniform substrate, conforming dielectric cells and finite exterior walls. Increase both `cells` and `margin` (multiples of the larger reference spacing) to test convergence. The output includes isolated single-line impedance, differential and common driving impedances, layer velocities, projected registration, widths, uncoupled spans and reference gaps. The cascade retains coupling between conductors. The odd/common scalar interpretation assumes a symmetric uniform cross section. A nonuniform multilayer dielectric or coplanar ground edge requires its own field model.

`step_mm` controls spatial sampling. Straight centerline intersections with plane boundaries create stations even for slots shorter than the sample pitch. Arcs use the true routed length and a chord approximation for slot detection. In monotone routes the tracks are registered along the propagation axis. For meanders that double back, specify increasing pairs of corresponding **interior** distances in `landmarks_mm` for the analyzed pair; otherwise inspect the reported fractional-arclength registration. `match` lists pairs of analyzed net names for clock-to-data or other inter-net comparisons. The section table records cumulative delay and the location of length and delay mismatch. Section impedance is unresolved inside an unsupported reference gap. The exported line cascade continues the nominal return there as an explicitly experimental estimate.

Specify increasing `frequency_hz`, optional `roughness_um` (RMS height), and single-ended `reference_ohm` (default 50). Loss includes symmetric slab skin impedance, a Hammerstad roughness factor on conductor resistance, finite return width, and dielectric loss from the electric-energy integral. Results include the lossless mismatch and separate conductor and dielectric insertion-loss increments. These isolated increments need not add exactly at discontinuities. The model omits detailed edge-current crowding, radiation, dispersive material relaxation and three-dimensional launch fields. Touchstone port order is near positive, near negative, far positive, far negative. The mixed file uses D1,2 C1,2 D3,4 C3,4 with differential and common references twice and half the single-ended reference. For a single line, ports 1 and 2 are near and far. [Touchstone 2.0 specification](https://ibis.org/touchstone_ver2.0/touchstone_ver2_0.pdf)

`design` can set a matched-line loss budget `loss_db` (at the highest sweep frequency), `skew_ps`, and a `single_ohm` target with `width_range_mm`. The `diff_ohm` target solves the edge gap in `gap_range_mm` at the resulting or supplied trace width. A target outside the search bracket has a null result. Length guidance uses the first applicable uniform section and excludes connectors and launch loss.

## Ground stitch proposals

Use a `stitching` array. Each case names the return `net`, foil layers (`layers`, default all), modeled `source` and `sink`, `current_A`, and a search region (`bounds_mm`), pitch `search_step_mm`, solver `mesh_mm`, and `max_vias`. Specify `land_mm`, `drill_mm`, `clearance_mm`, `hole_clearance_mm`, `edge_clearance_mm`, and center spacing `via_spacing_mm`. The geometric filter requires complete annular-land coverage, clearance from other nets, all pads and holes, board edges, via keepouts, graphical copper and prior candidates. `exclude_mm` accepts additional rectangular no-go zones. Use the larger constraints required by the applicable net classes. A design-rule file with conditional exceptions is not evaluated by this filter.

Objectives are `resistance` (Ω), `potential` (terminal voltage magnitude, V), `inductance` (H), or `islands`. For AC supply `frequency_hz`, `return_spacing_mm`, the effective `via_return_radius_mm` and the forward filament path (`exciting_path_mm`, xyz in mm, from the sink toward the source); `signal_net` also locates layer transitions. Inspect the solver's stated loop model. Refine spatial resolution and grow the model window before accepting a small improvement. A greedy selection reevaluates all feasible remaining candidates after each placement. The CSV files list chosen positions and all stage rankings. Independent cases represent alternative proposals; combining them needs a joint rerun.

Island diagnostics count ground through contacts on physical patches and on lobes separated by erosion at `neck_mm`. The largest continuous patch provides the reference for cross-layer connectivity. The two-contact deficit is a placement heuristic. It is not an EMC limit. Reported spacing/wavelength uses substrate `er` and `max_frequency_hz` (or the case frequency). Through pads contribute to electrical connectivity; nearest via spacing uses via barrels.

To export a **new** study copy, name exactly one case:

```sh
pcb-physics BOARD.kicad_pcb SETTINGS.json OUT --stitch-case "Foil connection" --write-vias NEW.kicad_pcb
```

The exporter refuses an existing destination, places the chosen through vias and refills the copy. Recheck its current paths and run KiCad DRC with the project's rules.

The CLI snapshots the board and settings before extraction. A cancelled or failed analysis keeps the last completed report. When reading a reused output directory, use the files listed in the current `provenance.json` and check their SHA-256 digests. A missing completion record indicates that the installation of the report is incomplete. New board proposals use the same input snapshot as the analysis.
